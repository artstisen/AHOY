Utility Editor:

A separate text editor useful for working in parallel with the main editor. The Utility Editor is not tied to a specific Entry, instead it uses four Memory Banks (Temp, A, B and C) to store its content, from which it is possible to transfer text to any selected Entry.

The Utility Editor will persist Memory Banks A, B and C (Autosave feature), including Window Size, Location and Opacity. As with normal Entries the Memory Banks are stored in the encrypted file repository. Content in the Temp Memory Bank will be discarded when AHOY! is closed.

Press ALT+Left/Right to cycle back and fourth between Memory Banks.
Press CTRL+ +/,/./- to insert Paragraph Dividers.

The Utility Editor can be placed anywhere on the screen and above the AHOY! window. Using the Opacity setting (found in the Menu) the Editor can serve as an overlay while working on multiple documents.
It is possible to create New Entries, edit and add content to existing Entries from the Utility Editor.
